# Spec: NFC URL 生成

## Purpose

設定画面から NFC タグへ書き込む URL を生成・コピーする機能。`mode: event` かつ `type: checkbox` の項目に対して `/quick-log?item_id=<item_id>` の URL を表示し、クリップボードへのコピーを提供する。

---

## Requirements

### Requirement: 設定画面からNFC用URLを表示・コピーできる

`ItemConfigScreen` は、`mode: event` かつ `type: checkbox` の項目に対して、NFC タグへ書き込む URL を生成・表示しなければならない（SHALL）。URL の形式は `/quick-log?item_id=<item_id>` とする。

> ID: NFCURL-001

#### Scenario: イベント項目にNFC URLが表示される
- **WHEN** ユーザーが設定画面を開き、`mode: event` かつ `type: checkbox` の項目が存在する
- **THEN** 各該当項目の下に `/quick-log?item_id=<item_id>` の URL が表示される

#### Scenario: NFC URLをクリップボードにコピーできる
- **WHEN** ユーザーがNFC URL横の「コピー」ボタンをクリックする
- **THEN** URL がクリップボードにコピーされる
- **THEN** ボタンのラベルが一時的に「コピー済み」に変わる

#### Scenario: form・status モードの項目にはNFC URLが表示されない
- **WHEN** ユーザーが設定画面を開く
- **THEN** `mode: form` または `mode: status` の項目にはNFC URL欄が表示されない

#### Scenario: checkbox 以外の type の event 項目にはNFC URLが表示されない
- **WHEN** ユーザーが設定画面を開く
- **THEN** `type` が `checkbox` 以外の `mode: event` 項目にはNFC URL欄が表示されない
